Certificate PDF Builder
=======================

1. Double-click CertificatePDFBuilder.exe (nothing to install).
   If Windows says "Windows protected your PC", click More info > Run anyway.

2. Click "+ Add files..." (or "Add folder...") and choose the device Excel files.
   The table shows a tick or a cross for each of the 4 tabs.
   Use the arrow buttons or "Sort A-Z" to set the order.

3. Choose where to save, tick Excel files and/or PDF files, then click "Create files".
     Certificates             - ECG.certificate + NIBP.certificate of every device
     Pass-Fail Test Sheets    - ECG.pass-fail + NIBP.pass-fail of every device
   Certificates.xlsx has 2 sheets: "ECG certificates" and "NIBP certificates".
   The Pass-Fail file has 2 sheets: "ECG reports" and "NIBP reports".
   Each sheet has every device one after another (a page break between them) and
   prints exactly like the original tab. Print > Print entire workbook prints both.

PDF files need Excel 2010 or newer, or the free LibreOffice (https://www.libreoffice.org).
Excel 2007 cannot save PDFs - install LibreOffice and the app will use it automatically.

The app never prints anything, and never changes your Excel files.
If your tabs have different names, click "Options..." to change them.
